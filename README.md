# 🍚 今日の献立

「今日なに食べよう…」を、ボタンひとつでランダムに決めてくれるアプリです。
スロットがくるくる回って、今日の献立をパッと提案します。

**▶ アプリを開く： https://ss-prg-sy.github.io/menu/**

スマホの縦画面での利用に最適化しています。

---

## こんなアプリ

- 主菜・副菜をランダムで提案
- 疲れた日は「手抜きモード」で軽めの料理だけに絞れる
- 決まった料理の材料もチェックできる
- 家族・2人以上で食べる前提のメニュー構成

もともとノーコードツール(Adaro)で作った献立アプリを、Webアプリとして作り直したものです。

---

## 使い方

1. スタート画面で **「主菜をきめる」** か **「副菜をきめる」** を選ぶ
2. 主菜の場合は **「普通」** か **「手抜き」** を選ぶ
   - 普通 … 全部の主菜から
   - 手抜き … 疲れた日向けの軽めの料理だけから
3. スロットが回って料理が決定！
4. 気に入らなければ **「引き直す」** でもう一回
5. **「材料をみる」** で使う食材を確認できる
6. 主菜が決まったあとは、下の **「＋副菜もつける？」** で副菜も追加できる

---

## 収録メニュー

| 区分 | 品数 |
|---|---|
| 主菜(手抜き) | 25品 |
| 主菜(普通) | 36品 |
| 副菜 | 11品 |
| **合計** | **72品** |

各料理に食材リスト(食材名のみ)を登録済み。

---

## 仕様のポイント

- 引き直しても、直前と同じ料理は続けて出にくいようにしている
- 主菜と副菜は別々に引き直せる
- 副菜はモードなし(いつでも全11品から)
- 材料は「見るだけ」。アプリ画面から勝手に編集はできない

くわしい仕様は [仕様書.md](仕様書.md) を参照。

## 技術メモ

- HTML / CSS / JavaScript を1つの `index.html` にまとめた単体ファイル構成
- 外部ライブラリ・ビルド不要。ファイルをブラウザで開くだけで動く
- GitHub Pages で公開

### メニューや材料を増やしたいとき

`index.html` の上のほう(コメントで囲った編集エリア)にある料理リストを編集します。

- `MAIN_LAZY` … 手抜きの主菜
- `MAIN_NORMAL` … 普通の主菜
- `SIDES` … 副菜
- `INGREDIENTS` … 各料理の材料

料理を追加したら `INGREDIENTS` にも同じ料理名で材料を足してください。
(半角の `"` で囲む / うしろに半角 `,` をつける、を守れば動きます)
